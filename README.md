# Net-Async-Authentik

Async Perl client for the [authentik](https://goauthentik.io/) identity provider
(IO::Async + Future): OIDC against an application plus the REST API (v3). The async twin
of `WWW::Authentik`, a structural sibling of `Net::Async::Keycloak`.

**Status: skeleton.** Nothing is implemented yet.
